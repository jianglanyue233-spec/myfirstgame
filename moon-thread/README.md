# Moon Thread

A five-level Godot 4.7.2 prototype about drawing magical patterns by walking while a Thread Eater erases the glowing path.

## Controls

- Arrow keys / WASD / Xbox left stick: move
- Space / Xbox A: cast a pulse that pushes the Thread Eater backward
- P / Escape / Xbox Start: pause

## Rules

Connect the glowing nodes in the displayed order before the 60-second timer or thread supply runs out. Crossing your own thread creates a Magic Knot that freezes the Thread Eater. Complete all five patterns to awaken the Moon Garden.
