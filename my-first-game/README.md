# Charms Seeker - playable prototype

Open `project.godot` with Godot 4.7.2 and press **F6/F5**.

## Controls

- Arrow keys / Xbox left stick: move Luna
- Space / Xbox A: activate one stored Moonlight Energy
- P / Escape / Xbox Start: pause

## Implemented from the GDD

- 60-second single-round maze chase
- 180 Stardust Pearls, four Moonlight Energy pickups, and refill bonus
- Three lives and 1.5-second post-hit invulnerability
- Three starting Shadow Cats; one is added at 40s and 20s remaining
- Eight-second petrification, escalating 50/100/200/400 cat combo, and 5-second respawn
- Bronze/Silver/Gold chest thresholds, random charm reward, local leaderboard and collection save
- 480x270 logical viewport with integer-friendly procedural pixel art

This prototype uses generated shapes so it is immediately playable without waiting for final art or audio assets.
